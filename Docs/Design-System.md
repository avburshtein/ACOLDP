# Дизайн-система — AI Context Orchestrator (ACOLDP)

> Правила визуального языка UI. Этот документ — источник истины: если стиль
> меняется в коде, меняем и здесь. Обратное тоже верно: новый UI пишем по этим
> правилам, а не «по вкусу».

**Источники стилей:**

| Файл | Что содержит |
|------|--------------|
| `src/ui/styles/theme.css` | Токены тем: ч/б палитра `--md-sys-color-*` |
| `src/ui/styles/base.css` | `@layer components`: `.field-surface`, glass-система, `.custom-scrollbar` |
| `src/ui/components/ui/*` | Компоненты (Button, Input, Textarea, Select, Dialog, …) |

---

## 1. Темы и токены

- Две темы: **light** (белый фон + чёрный акцент) и **dark** (чёрный фон + белый акцент).
- Переключение — атрибут `data-theme="light|dark"` на `<html>`, выбор в localStorage.
- Tailwind dark-вариант настроен через `@custom-variant dark` в `base.css` —
  классы `dark:*` реагируют на `data-theme`, а не на системную тему ОС.
- Ключевые токены: `background`, `surface`, `surface-variant`, `on-surface`,
  `on-surface-variant`, `outline`, `outline-variant`, **`outline-active`**,
  `primary` / `on-primary`, `secondary-container`, `error`.

### Токен `outline-active` — активная линия полей

Линия из glass-палитры, которой подсвечивается бордер полей в активном состоянии:

| Тема | Значение |
|------|----------|
| Light | `rgba(95, 90, 110, 0.35)` — контурный серо-фиолетовый из glass |
| Dark | `rgba(255, 255, 255, 0.26)` — бордер glass-кнопки в hover |

## 2. Кнопки — glass-система

Все кнопки имитируют матовое стекло: `backdrop-blur` + полупрозрачная заливка +
**переливающаяся кромка** (`::before`, конический градиент-дисперсия) +
**спекулярный блик** (`::after`, появляется на hover) + мягкие тени.

Варианты (`button.tsx` + правила в `base.css`):

| Вариант | Класс | Назначение |
|---------|-------|------------|
| `default` | `glass-accent` | Главный CTA («Отчёт», «Войти») — тёмное дымчатое стекло |
| `secondary` | — | Нейтральное действие («В Jira», «Гостевой вход», «Демо») |
| `ghost` | `glass-ghost` | Служебные/иконочные кнопки — приглушённые (55–70%) |
| `destructive` | `ghost` + `data-destructive` | **Единственная кнопка с особым hover-цветом** — румяная кромка и гало («Очистить») |

**Иерархия hover** (важно!): `ghost` — самый тихий < `secondary` / `default` —
блик + микроподъём `translateY(-1px)` + бордер `0.26` (dark). Отдельный яркий
hover допустим только у destructive. Иконки Lucide — монохромные, приглушённые
через `svg { color: … }` в glass-правилах.

## 3. Поля ввода — `.field-surface` (ПЛОСКИЕ, не стекло!)

**Правило:** все поля (textarea, input, триггер Select) — плоские контролы на
серой подложке. Стекло — только для кнопок. Смешивать нельзя.

| Состояние | Фон | Бордер |
|-----------|-----|--------|
| Покой | `surface-variant` | `outline-variant` (серый) |
| Hover | `surface-variant` | `outline-active` |
| Focus / Focus-visible | `surface-variant` | `outline-active` |
| Select открыт (`[data-state='open']`) | `surface-variant` | `outline-active` |

- Реализация: класс `.field-surface` в `base.css` (@layer components).
- Базовые компоненты уже включают его: `ui/Input`, `ui/Textarea`, `ui/SelectTrigger`.
- **Фокус-подсветка — только бордером.** `ring-2` / `ring-primary` на полях
  запрещены (устаревший стиль, даёт «слепящую» рамку).
- Для полей на сером фоне (внутри сгруппированных блоков, как Jira в настройках)
  переопределять фон на `bg-[var(--md-sys-color-surface)]` — utility перебьёт
  `field-surface` (utilities-слой старше components), бордер наследуется.
- **Drop-zone** — пунктирный вариант того же паттерна: класс `.field-surface-dashed`
  (покой — серый пунктир без заливки; hover/focus — бордер `outline-active`;
  drag-over — бордер `outline-active` + заливка `surface-variant`). Активация
  через `data-dragover={dragOver || undefined}`; зона доступна с клавиатуры
  (`tabIndex` + `role="button"` + Enter/Space).

## 4. Select и комбо-поля

- Триггер = `.field-surface` (см. §3); открытое состояние подсвечивается тем же
  правилом `[data-state='open']` — отдельные стили не нужны.
- Дропдаун (`SelectContent`): `surface` + бордер `outline-variant` + `shadow-md`.
- Пункты (`SelectItem`) поддерживают проп `icon` — монохромные иконки Lucide
  слева от текста; иконка НЕ входит в `ItemText`, чтобы не задваиваться в триггере.
- **Поле с подсказками (модель LLM)** — свободный ввод + собственный дропдаун
  с шевроном `ChevronDown` (тот же, что у Select). Нативный `datalist` не
  используем: браузерный шеврон не стилизуется и выбивается из системы.
- **Позиция дропдауна комбо-поля**: карточки имеют `overflow-hidden`, а такой
  дропдаун не портальный (в отличие от Radix Select) — если поле стоит у правого
  края карточки, список выравнивается по `right-0` и раскрывается влево.
- **Геометрия контролов единая**: высота `h-9`, боковые паддинги `12px`
  (`pl-3` / шеврон `right-3`), шеврон `h-4 w-4 opacity-50`, текст `text-body-md`
  (размер и вес — как у значения Select), цвет `on-surface` /
  placeholder `on-surface-variant`. Ширина может отличаться (w-28 / w-full).

## 5. Правила-запреты (шпаргалка ревьюера)

1. ❌ Стекло на полях ввода — стекло только на кнопках и карточках-акцентах.
2. ❌ `ring-*` на фокус полей — подсветка только бордером (`outline-active`).
3. ❌ Цветные иконки/эмодзи в контролах — иконки монохромные Lucide.
4. ❌ Свой hover ярче CTA — иерархия: ghost < secondary/default; «кричит» только destructive.
5. ❌ Дублирование стилей бордера/фона полей инлайн-классами — используйте `.field-surface`.
6. ✅ Новые темы/значения — через токены `theme.css`, не хардкодом в компонентах.

---

## 6. Структура экрана (референс)

- Шапка: заголовок + бейдж режима сессии (провайдер / «Демо-режим»-кнопка) + theme-toggle + настройки.
- Сетка: две карточки `lg:grid-cols-2` — вход (слева) и результат (справа).
- Вход: заголовок секции + Демо + поле модели → Select режима → описание режима →
  подсказка модели (`Cpu`) → textarea → drop-zone → счётчик (+ предупреждение >30k) →
  кнопки: Очистить (destructive-ghost) | spacer | CTA режима | В Jira (secondary).
