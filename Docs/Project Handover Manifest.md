⚡ Project Handover Manifest: AI Context Orchestrator (ACOLDP)
Назначение документа: Быстрый ввод нового ИИ-коллеги или разработчика в архитектуру, текущий статус и стек проекта ACOLDP.

🎯 1. Концепция и цель проекта
AI Context Orchestrator & Living Documentation Platform (ACOLDP) — это единая панель управления контекстом для solo-разработчика и команды ИИ-агентов из разных сервисов (Gemini, Claude, ChatGPT, Qwen).

Главные задачи системы:
Сбор "сырого" контекста: Приём неотструктурированных дайджестов, логов чатов, файлов кода (.js, .py), документов (.docx, .md) и баг-репортов.

Генерация Daily Digest: Преобразование хаоса в идеальный ежедневный Markdown-отчёт с разбором прогресса, архитекторских решений, блокеров и списка готовых задач.

Умная синхронизация с Jira (Atlassian): Автоматическое сопоставление новых задач с открытыми тикетами в бэклоге (дедупликация, повышение приоритета, комментирование или создание Task/Bug).

Context Flow между ИИ: Передача структурированного контекста разработки без потери деталей.

🏗️ 2. Текущая архитектура и Стек
Проект реализует Serverless / No-Backend подход с упором на максимальную автономность и быстродействие.

Frontend & Edge Backend: Единый Cloudflare Worker (All-in-One архитектура), отдающий клиентский UI и обрабатывающий REST API запросы (GET для UI, POST для генерации и синхронизации).

LLM Engine: Google Gemini API (generativelanguage.googleapis.com).

Issue Tracker: Jira Cloud REST API (rest/api/2/).

UI Design System: Тёмная тема в стиле Google Stitch, автосохранение черновика в localStorage, модальные окна авторизации и настроек.

Экспорт данных: Быстрое сохранение отчётов в .md, .html, .txt и скопировать в буфер.

✅ 3. Что уже реализовано и работает (v7.5 / v9.0)
🎛️ Клиентская часть (UI & DX)
All-in-One Single File: Код UI и бэкенда скомпонован в едином файле worker/index.js без сторонних npm-зависимостей.

Надёжная авторизация: Форма с поддержкой autocomplete="current-password", работающая по нажатию Enter на мобильных и планшетах (iPad).

Безопасность черновиков: Автосохранение текста в localStorage каждые 500 мс с индикацией ✓ Черновик сохранен + модальное окно с подтверждением очистки.

Приём файлов (Drag & Drop): Поддержка перетаскивания и загрузки файлов (.txt, .md, .js, .py, .json, .docx) с автоматическим оборачиванием в Markdown-блоки кода.

Управление запросом: Наличие кнопки ⛔ Стоп (AbortController), позволяющей в 1 клик прервать затянувшийся запрос к API.

Панель настроек (Settings Modal): Возможность прямо из браузера переопределить API-ключи (Gemini API Key, Jira Domain, Project Key, Email, Token), сохраняемые локально.

Гибкий выбор модели: Селектор с возможностью выбора стандартных моделей или ввода произвольного имени модели вручную (CUSTOM).

🛠️ Бэкенд и Инфраструктура
Защита от сбоев Gemini API (503 / 429 / 404): Написана функция callGeminiWithRetry с паузами (Exponential Backoff) и каскадным переключением (Fallback) по списку рабочих моделей:
gemini-flash-latest ➔ gemini-2.0-flash ➔ gemini-2.0-flash-lite ➔ gemma-4-31b-it.

Умный авто-анализ ошибок в промпте: Системная инструкция генератора отчётов автоматически анализирует логи сбоев API (429 Rate Limits, 503 High Demand, CORS, Syntax Errors) и вносит их в раздел «🛑 Блокеры и найденные баги».

Два режима работы Worker:

mode === 'REPORT' — сборка красивого дневного Markdown-дайджеста.

mode === 'JIRA_SYNC' — получение открытых тикетов через JQL, отправка структуры в Gemini с JSON Schema и автоматическое создание/обновление задач через REST API Jira.

Связка отчётов и Jira: Кнопка ⚡ В тикеты Jira над результатом генерации отчёта, подставляющая текст дайджеста в алгоритм синхронизации задач в 1 клик.

🚧 4. Текущие блокеры и проблемы в работе
Деградация на длинных контекстах после v7.5:

Симптом: В экспериментальных версиях (v10.x) при передаче большого объёма чатов наблюдалось существенное замедление или сбои обработки.

Решение: Архитектура временно откатана до стабильной версии v7.5, проводится сравнительный анализ промптов и конфигураций API (thinkingBudget, размер передаваемых системных инструкций).

Лимиты Free Tier Gemini API (429 Rate Limit):

Симптом: На бесплатном тарифе установлены жесткие ограничения (до 20 запросов/день на Flash-модели или минутные лимиты по токенам).

Решение:

Использование каскадного Fallback на другие доступные модели.

Планируется привязка billing-аккаунта (Pay-as-you-go) в Google Cloud для безлимитной работы за копейки ($0.0001/запрос).
