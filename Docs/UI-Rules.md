# UI Rules — ACOLDP (правила реализации интерфейса)

> ⚠️ ВНИМАНИЕ ИИ-АГЕНТУ: правила обязательны для любого изменения UI.
> Хардкод HEX-значений, пикселей и произвольных размеров внутри компонентов —
> ЗАПРЕЩЁН. Всё через токены `theme.css` и утилиты из `base.css`.
>
> **Отношение к `Docs/Design-System.md`:** тот документ описывает визуальный
> язык поверхностей (стекло, поля, темы, токены); этот — правила реализации
> (сетка, геометрия, типографика, состояния, тексты, доступность). Конфликт —
> решается в пользу Design-System по поверхностям и в пользу этого документа
> по структуре. Оба обновляем вместе с кодом.

**Стек:** React + TypeScript + Tailwind CSS v4, токены MD3 (`--md-sys-color-*`),
UI-примитивы из UX42. Никаких дополнительных UI-библиотек.

---

## 1. Импорт и библиотеки

- UI-примитивы — только через `import { Button, Card, Dialog } from '@/components/ui';`
- Иконки — только `lucide-react`. `@mui/icons-material`, emoji-иконки в контролах — запрещены.
- Слияние классов — только `cn()` из `@/lib/utils` (clsx + tailwind-merge).
- Варианты компонентов — через `cva` (class-variance-authority), как в `button.tsx`.
- Новая UI-библиотека / зависимость для «одной кнопки» — не добавляется без обсуждения.

## 2. Сетка и отступы (Layout & Spacing)

- **Базовый шаг: 4px**, полушаг 2px допустим в плотных скоплениях
  (иконка рядом с иконкой). Канонические значения: 4 / 6 / 8 / 12 / 16 / 24.
  Произвольные `[13px]`, `[7px]` — запрещены.
- **Паттерны приложения (соблюдать, не изобретать заново):**
  - Шапка страницы: `px-4 py-3.5`, нижний бордер `outline-variant`.
  - Контент: `grid grid-cols-1 lg:grid-cols-2 gap-4 p-4`; карточки `h-full min-h-0 overflow-hidden`.
  - Панель (вход/результаты): `flex h-full flex-col gap-3 p-4`.
  - Внутри панелей: группы с `gap-2`, плотные ряды иконок — `gap-1.5`.
  - Карточка результата/артефакта: `p-4`.
- Настройка Layout Shift: фиксированные высоты контролов (`h-9`), резервируй
  место под предупреждения/счётчики, чтобы текст не «прыгал» при появлении.

## 3. Скругления (Shapes)

| Элемент | Радиус |
|---------|--------|
| **Все кнопки** (система cva в `button.tsx`) | `rounded-full` |
| Круглые icon-кнопки шапки | `rounded-full` (h-10 w-10) |
| Поля ввода, Select-триггеры, дропдауны, комбо-списки | `rounded-md` |
| Карточки, диалоги, бäннеры результата | `rounded-xl` |
| Бейджи (Badge) | по компоненту (`rounded-full`) |

Произвольные радиусы (`rounded-[10px]`) — запрещены: либо примитив, либо
исключение через обсуждение и запись сюда.

## 4. Типографика

Единственный шрифт — **Inter**; моно — **JetBrains Mono** (цифры, счётчики,
исходный markdown). Только утилиты typescale из `base.css` (`@theme`),
произвольные `text-[17px]` — запрещены.

| Сущность | Класс |
|----------|-------|
| Заголовок страницы (шапка) | `text-headline-lg` |
| Заголовок секции панели («1. Входные данные») | `text-title-sm font-semibold` |
| Заголовок карточки результата/артефакта | `text-label-md font-semibold tracking-wide` |
| Основной текст (textarea, описания) | `text-body-md` |
| Вторичный текст, превью, описания под контролами | `text-body-sm` |
| Подсказки, лейблы, mode-описания | `text-label-sm` / `text-label-md` |
| Счётчик символов, мелкие служебные | `text-xs` |
| Секундомер, крупные цифры | `font-mono` (размер по контексту) |
| Текст markdown-результата | `font-mono text-body-sm leading-relaxed` |

Цвет текста: основной — `on-surface`, вторичный — `on-surface-variant`
(подсказки, placeholders, даты). Заголовки — `on-surface`.

## 5. Кнопки

Варианты (назначение — не «какой красивее», а роль действия):

| Вариант | Размер | Назначение (примеры из приложения) |
|---------|--------|-------------------------------------|
| `default` (CTA) | `sm` в панелях | Одно главное действие панели: «Отчёт/Дайджест/Кейс», «Войти» |
| `secondary` | `sm` | Значимое вторичное действие: «В тикеты», «Дополнить», «Открыть» (история), «Демо» |
| `ghost` | `sm` / `icon` | Служебные и иконочные: Copy, Download, Google Docs, Stop |
| `ghost` + `data-destructive` | `sm` | Деструктив — «Очистить». Единственная кнопка с особым hover |
| `link` | — | Инлайн-ссылка в тексте («Открыть →» в карточках Jira) |

Правила:

- **Одна `default`-кнопка на зону.** В ряду действий максимум один CTA.
- Иконка в кнопке: `h-4 w-4` (default/secondary), `h-3.5 w-3.5` (sm), слева от текста.
- `disabled` — для busy-состояний и недоступных действий; кнопка остаётся видимой
  (не скрывать), чтобы не дёргался layout.
- Круглые icon-кнопки шапки — паттерн `iconBtnCls` из `app.tsx`
  (`h-10 w-10 rounded-full glass glass-shadow` + focus-visible ring), не городить своё.
- Иерархия hover и инверсия CTA в dark — см. Design-System §2 (не дублировать стили вручную).

## 6. Поля ввода и Select

Поверхности — по Design-System §3–4 (`.field-surface`, плоские, фокус бордером).
Здесь — только правила реализации:

- Высота всех контролов — `h-9`; текст `text-body-md`; placeholder и подсказки —
  `text-label-sm`/`text-body-sm` цвета `on-surface-variant`.
- Подсказка-строка под контролом (как «Модель: …» с иконкой `Cpu`) —
  `text-label-sm leading-snug` + `flex items-start gap-1.5`, иконка `h-3.5 w-3.5 mt-0.5`.
- Счётчики и предупреждения под полями — `text-xs`, выравнивание `px-1`,
  предупреждение — `text-amber-600 dark:text-amber-400` (временное исключение, см. §8).
- Дропдауны без портала (`overflow-hidden` у карточки): у правого края —
  `right-0 top-full` (раскрытие влево), `z-50`, `w-44` по контенту. Пункты —
  `px-2.5 py-1.5 text-body-md`, hover `surface-variant`, `role="listbox"/"option"`.
- `datalist` — запрещён (нестилизуем), только комбо-паттерн с `ChevronDown`.

## 7. Иконки

- Только Lucide, монохромные; размер наследует текст (стекло приглушает через `svg { color }`).
- Размеры: `h-4 w-4` — кнопки default/secondary; `h-3.5 w-3.5` — sm-кнопки и
  инлайн-подсказки; `h-5 w-5` — круглые кнопки шапки; `h-10 w-10` — пустые состояния.
- Декоративная иконка — `aria-hidden`; кликабельная icon-кнопка — `aria-label` + `title`.
- **Эмодзи допустимы только как контент текста**: сообщения статусов (`✓`, `⏹`, `❌`)
  и заголовки карточек результатов («📋 Отчёт»). Эмодзи вместо иконки в кнопке,
  лейбле поля, пункте списка — запрещено.

## 8. Цвет и статусы

- Только токены `--md-sys-color-*`; сырые hex и `rgb()` в компонентах — запрещены
  (opacity-модификаторы токенов вида `outline-variant` через `border-*` — ок).
- Семантика текста: `on-surface` — контент, `on-surface-variant` — всё вторичное.
- Ошибки (карточка ошибки, строки ошибок Jira): сейчас `border-red-400/40` +
  `text-red-400` — **временное исключение**; целевое состояние — токены
  `--md-sys-color-error*` (задача миграции, не блокер).
- Предупреждения: `text-amber-600 dark:text-amber-400` — то же исключение.
- Каждое цветовое решение проверяется в **обеих** темах (light и dark).

## 9. Скролл, переполнение, поток

- Любая скролл-область — `custom-scrollbar` (класс из `base.css`).
- Панели/карточки: `min-h-0` + `overflow-hidden`/`overflow-y-auto` (иначе flex
  не даёт скроллу работать внутри `h-screen` сетки).
- Markdown результата: `<pre>` с `whitespace-pre-wrap break-words`,
  `max-h-[60vh]`, автоскролл при стриме (`scrollTop = scrollHeight`).
- Превью в списках — `line-clamp-2`.
- Внутри карточек с `overflow-hidden` не-портальные дропдауны — по правилу §6.

## 10. Состояния и обратная связь

| Состояние | Паттерн |
|-----------|---------|
| Генерация (стрим) | live `pre` + бейдж «Генерация…» + mono-секундомер + кнопка Stop |
| Ожидание (не-стрим) | спиннер + mono-секундомер + текст-подсказка по секундам |
| Пусто | центрированная заглушка: иконка + `text-body-md`, приглушённая |
| Успех/инфо | StatusBadge: `✓ …`, авто-скрытие; кратко, без художеств |
| Остановка | `⏹ Остановлено — частичный результат сохранён` |
| Ошибка | error-карточка с полным сообщением (включая `[provider/model] HTTP …`) |
| Демо | пунктирный баннер `border-dashed` |
| Деструктив | `confirm()` перед действием; пустой ввод — `alert` с объяснением |

- Тексты статусов — по единому шаблону «✓ Действие выполнено» (глагол + результат).
- Всегда объясняй, что делать дальше («вставь материал…», «нажми Ctrl+V»).

## 11. Доступность

- Кликабельные не-кнопки (drop-zone, бейджи-кнопки): `tabIndex={0}`,
  `role="button"`, обработка `Enter`/`Space`, `focus-visible:outline-none`
  + `focus-visible:ring-2 ring-[var(--md-sys-color-primary)] ring-offset-2`.
- Icon-only кнопки — обязательно `aria-label` + `title` (совпадают по смыслу).
- Спиннер загрузки — `role="progressbar"` + `aria-label`.
- Комбо-дропдауны: `role="combobox"` на поле, `aria-expanded`,
  `role="listbox"/"option"`, `aria-selected`, закрытие по Escape.
- Контраст проверяем на ч/б палитре: вторичный текст — только `on-surface-variant`,
  не «серый на глаз».

## 12. Реестр компонентов (проверяй перед созданием нового)

| Задача | Компонент (`@/components/ui`) |
|--------|-------------------------------|
| Любая кнопка | `Button` (cva-варианты, см. §5) |
| Карточка/панель | `Card` (+ `rounded-xl` паттерн `cardCls`) |
| Поле ввода / многострочное | `Input` / `Textarea` (уже с `field-surface`) |
| Выбор из списка | `Select` (+ проп `icon` у `SelectItem`) |
| Свободный ввод + подсказки | комбо-паттерн (см. Design-System §4) |
| Модалка | `Dialog` (Settings, подтверждения) |
| Переключатель видов | `Tabs` (панель «Результат | История») |
| Бейдж/статус | `Badge` (`surface`/`outline`) |
| Тост-уведомления | `StatusBadge` + `useStatus()` |
| Списки выбора даты и пр. | пока не используется — не тащить |

## 13. Чеклист ревью UI-изменений (прогонять перед коммитом)

1. Обе темы: light и dark (контраст, стекло, кромки).
2. Оба лейаута: одна колонка (`<lg`) и две (`lg:grid-cols-2`).
3. Правый край: не-портальные дропдауны не обрезаются (`right-0`-правило).
4. Отступы кратны шагу сетки (§2); радиусы из таблицы §3.
5. Иерархия кнопок: один CTA, ghost тише secondary (§5).
6. Иконки Lucide + размеры по контексту; эмодзи только в текстах (§7).
7. Скролл: `custom-scrollbar`, `min-h-0`-цепочка, ничего не «залипает».
8. Клавиатура: tab-порядок, focus-visible, Enter/Space на кастомных кнопках (§11).
9. Состояния: пустое/загрузка/ошибка/демо отрисованы, тексты по шаблону §10.
10. `npm run typecheck` — чисто.
